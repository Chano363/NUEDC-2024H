# 自动行驶小车 · 2024 全国大学生电子设计竞赛 H 题

小车在指定场地内完成定点停车、双半圆弧路径行驶与多圈循迹任务。本仓库为 2024 年参赛实现，代码基于 TI MSPM0G3507，在准备 2026 年赛题期间完成并整理。

## 技术栈

- **主控**：TI MSPM0G3507，C 语言，ARM Cortex-M
- **感知**：灰度传感器循迹、ICM42688 六轴陀螺仪（UART，115200）
- **执行**：PWM 电机驱动、差速转向、编码器里程计
- **交互**：OLED 显示（硬件 I2C）、按键模式选择、蜂鸣器提示
- **控制**：航向 PD 修正 + 位置 PID 闭环、半圆循迹专用丢线策略

## 任务与实现

系统提供 A/B/C 三种模式，由 KEY2 长按循环选择、KEY1 长按启动：

- **A 模式**：AB 航向保持直线行驶，到 B 点停车。
- **B 模式**：AB 直线 → BC 半圆循迹 → CD 直线 → DA 半圆循迹，回到 A 点停车。
- **C 模式**（第三问）：AC/BD 对角线航向保持、CB/DA 半圆循迹及 B 点转向，完成多圈运行。

半圆段采用专用丢线策略：短暂丢线时保持最近弯向继续前进，重新检测到黑线后恢复位置 PID，避免原地搜索破坏半圆轨迹。模式 B 的圆弧退出增加双重判据——航向角需先达到 160°，且中间两路传感器连续多个控制周期重新稳定采到直线，防止车体尚未驶出半圆就误切换到直线段。

## 我负责的部分

主导三问状态机 `h3_task` 的设计与实现，完成 A/B/C 三种模式的流程控制、航向保持与半圆循迹的切换逻辑；实现 ICM42688 陀螺仪 UART 数据接收与连续航向解算、编码器里程计；设计半圆段丢线保持与圆弧退出判据，解决车体过早切出半圆的问题；完成 OLED 状态显示与按键交互，并整理三份移植/调参文档供实车标定。

## 关键实现

**陀螺仪航向 PD 修正。** 当前控制架构为"陀螺仪航向 PD 修正 + 电机 PWM 开环输出"：航向误差经 PD 运算产生左右轮目标 PWM。陀螺仪零点与正方向需实车标定，模式 C 还需设置 A→C 初始航向偏移（车头沿 AB 放置时约 ±52.73°，沿 AC 放置时设为 0）。

**圆弧退出双重判据。** 仅凭丢线判断圆弧结束会导致提前切换。加入航向角阈值（160°）与中间传感器稳定计数（`S4/S5`，偏差 ≤ 10 且连续 5 个控制周期）两个条件，兼顾"退出过早"和"丢线时退出过晚"两种失效模式。

**分层调参。** 参数集中在 `h3_config.h`：直线速度、半圆速度、最大航向修正量、圆弧退出角度与稳定周期、C 模式圈数、原地对准最小 PWM 等，配合 `docs/car_question3_porting/TUNING.md` 中的症状—参数对照表逐项整定。

## 调试记录

- **圆弧退出过早**：车体仍在转弯时误切到直线段，通过提高航向角阈值与中间传感器稳定周期解决。
- **原地对准不动/过冲**：分别调整 `H3_CFG_ALIGN_MIN_PWM` 与转向环 `TURN_KP`/`TURN_KD`。
- **参数耦合**：直线振荡、半圆速度、退出时机等参数互相影响，按"一次只调一个参数"的原则在实车上逐项标定。

## 运行环境

- Keil MDK（ARM），MSPM0G3507 芯片支持包
- 上电后先标定陀螺仪零点与正方向，再按移植记录的顺序验证（OLED → 低速直线 → 三问状态机）
- `H3_GYRO_TO_MOTOR_SIGN` 与速度/PD 参数需按实车方向标定
